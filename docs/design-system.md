# 面试记忆助手 · 设计规范 v1.0

> Interview Memory Assistant — 把面试经历，写成可回想的记忆。

这是「面试记忆助手」的完整视觉与交互规范。它解释这套界面为什么长这样、每个颜色和字号从哪来，以及新增页面时怎样保持同一种气质。

- 在线规范页：启动项目后访问 <http://127.0.0.1:8090/styleguide>
- Token 源文件：`web/src/styles/tokens.css`
- 视觉层：`web/src/styles/theme.css`
- 结构层：`web/src/styles/main.css`

---

## 1. 概念

面试准备通常被做成一个「后台」：蓝紫渐变、玻璃卡片、数据看板。它很现代，但也很像别人的工具。

这个项目换了一个隐喻：**一本摊在桌上的面试手记**。

- **纸**是底色，负责长时间阅读的舒适度；
- **墨**是正文与侧栏，负责信息密度与秩序；
- **朱砂**只留给真正重要的东西：今天要回想、记忆状态、主操作、重点标记；
- **编号、细线、页脚、批注**让页面有编辑感，而不是组件堆叠感。

它不追求「更像一个 SaaS」，而追求「愿意每天打开一次」。

### 适用场景

- 个人、单机、长时间使用；
- 以阅读题目、写答案、主动回想为主；
- 需要一点仪式感，但不能牺牲操作效率。

### 不适用场景

- 多人协作、强营销落地页、需要高饱和品牌色的产品；
- 需要大量图表同屏的 BI 大屏（本规范会显得太安静）。

## 2. 设计原则

### 2.1 纸先于屏

所有容器先是「纸片」，再是「卡片」。用暖白、细边框、极轻的硬阴影建立层次，而不是用大面积渐变和发光。

- 页面底色：`--paper`
- 纸片：`--surface`
- 边界：`1px solid --border`
- 层叠：`3px 3px 0` 的硬阴影，透明度不超过 8%

### 2.2 墨分五色，但只用一个强调色

正文用墨色，辅助信息用淡墨，真正需要被看见的用朱砂。苔绿、赭石、石青只做分类与状态，不抢主操作。

一条经验：**一屏里朱砂的面积不超过 8%**。它出现在主按钮、今日到期、记忆状态环、品牌印章和重点标记上，就够了。

### 2.3 衬线负责记忆，无衬线负责效率

- 大标题、数字、品牌字用衬线（Georgia / Songti / Noto Serif）；
- 正文、表单、按钮用无衬线（Segoe UI / 微软雅黑 / PingFang）；
- 编号、日期、标签、快捷键用等宽（Consolas / SFMono）。

这不是装饰：衬线让标题有「被写下来」的感觉，无衬线保证 14px 正文仍然清楚，等宽让元信息像页边批注。

### 2.4 动效是纸的惯性

只用 `transform` 与 `opacity`；时长 120 / 180 / 260ms；缓动以 `ease-out` 为主。悬停是「纸片被指尖按住，轻轻抬起」，不是「元素飞进来」。

### 3.3 用色规则

- **主色只做动作与状态**，不做大面积背景；唯一例外是品牌印章和 Hero 的朱砂点。
- **分类色来自内容**（Java、Spring、数据库……），由 `Category.color` 存储；展示时用 `color-mix` 与正文色混合，保证在亮 / 暗色下都可读。
- **不要新增第六种颜料**。需要更多分类时，优先复用已有色，或使用同一色相的深浅变化。
- **状态色不单独依赖颜色**：难度、记忆状态、结果都同时有文字标签。

## 4. 字体与排版

### 4.1 字体栈

```css
--font-display: Georgia, 'Times New Roman', 'Songti SC', 'Noto Serif SC',
                'Source Han Serif SC', SimSun, serif;
--font-body: 'Segoe UI', 'Microsoft YaHei', 'PingFang SC',
             'Hiragino Sans GB', sans-serif;
--font-mono: 'Consolas', 'SFMono-Regular', 'Courier New', monospace;
```

不引入 Web Font：减少首屏请求，也避免中文衬线在不同网络下闪烁。系统字体已经能覆盖 Windows / macOS 的主要阅读场景。

### 4.2 字号阶梯

| 角色 | 字号 | 字体 | 行高 | 场景 |
| --- | --- | --- | --- | --- |
| Display | 44px | Serif | 1.08 | 设计规范封面、空态大标题 |
| Hero | 34px（移动 23px） | Serif | 1.25 | 今日页问候语 |
| H1 | 30px | Serif | 1.2 | 页面主标题（详情页） |
| H2 | 22px | Serif | 1.3 | 区块标题 |
| H3 | 17px | Serif | 1.4 | 卡片小标题 |
| Body | 14px | Sans | 1.7 | 正文、表单 |
| Small | 12px | Sans | 1.5 | 辅助说明 |
| Micro | 10.5px | Mono | 1.4 | 编号、日期、标签 |

规则：

- 正文不小于 12px；大段阅读区域使用 14px / 1.75。
- 中文标题不要用 700 以上的字重，600 足够；衬线字体过粗会失去书卷气。
- 数字使用 `font-variant-numeric: lining-nums tabular-nums`，保证统计卡与表格对齐。
- 英文元信息统一大写 + `letter-spacing: 0.08em ~ 0.16em`。

### 4.3 版式细节

- 页面主内容最大宽度 `1360px`，左右留白 34px；移动端 14px。
- 区块标题前有两位编号（`01`、`02`），等宽、淡墨、字距拉开。
- 引用与批注使用 2px 朱砂左边线，不用整块底色。
- 分隔线优先 1px 实线；虚线只用于「可添加 / 空位」。
- 圆角克制：卡片 8–10px，标签 3–4px，按钮 5–6px；不要全站 16px 大圆角。

## 5. 间距、圆角与阴影

### 5.1 间距

| Token | 值 | 用途 |
| --- | --- | --- |
| `--s1` | 4px | 图标与文字、紧密元素 |
| `--s2` | 8px | 标签间距、行内间隔 |
| `--s3` | 12px | 表单控件内间距 |
| `--s4` | 16px | 卡片内小间距 |
| `--s5` | 24px | 卡片 padding、区块间距 |
| `--s6` | 32px | 大区块间距 |
| `--s7` | 48px | 页面级留白 |
| `--s8` | 64px | 封面 / 空态留白 |

### 5.2 圆角

| Token | 值 | 用途 |
| --- | --- | --- |
| `--radius-sm` | 6px | 输入框、按钮、标签 |
| `--radius` | 8px | 题目卡、面试卡、表格容器 |
| `--radius-lg` | 12px | Hero、弹窗、规范面板 |

### 5.3 阴影

```css
--shadow: 0 1px 0 rgba(32,29,22,.04), 0 10px 24px -20px rgba(32,29,22,.35);
--shadow-lg: 0 24px 50px -34px rgba(32,29,22,.4);
--shadow-hard: 3px 3px 0 rgba(32,29,22,.06);
```

- 常规卡片用 `--shadow-hard`，制造「纸片叠放」的偏移感。
- 浮层、粘性侧栏用 `--shadow` / `--shadow-lg`。
- 暗色下硬阴影改为黑色 25%，避免发灰。
- 禁止彩色发光阴影（旧版的 indigo glow 已全部移除）。

## 6. 布局

### 6.1 整体骨架

```
┌──────────────┬──────────────────────────────────────────┐
│  Ink Sidebar │  Topbar（68px，纸色半透明 + 模糊）        │
│  248px       ├──────────────────────────────────────────┤
│  书封 / 导航 │  Content（max 1360px，34px 左右留白）     │
│  连续回想    │                                          │
│  主题 / 规范 │  Page：Hero → 统计 → 主栏 / 侧栏          │
└──────────────┴──────────────────────────────────────────┘
```

- 侧栏固定，`--sidebar-w: 248px`；折叠后 `78px`，只留图标。
- 顶栏高度 68px，背景 `color-mix(in srgb, var(--bg) 88%, transparent)` + `backdrop-filter: blur(10px)`。
- 内容区进入时子元素按 35ms 递进上浮 8px，整体不超过 260ms。

### 6.2 断点

| 断点 | 行为 |
| --- | --- |
| `> 1240px` | 完整双栏：主栏 + 280px 侧栏；Hero 左右分栏 |
| `1024–1240px` | 侧栏仍完整，Hero 单栏，统计卡两列 |
| `860–1024px` | 侧栏自动折叠为 78px；顶栏隐藏日期；Hero 侧栏隐藏 |
| `700–860px` | 题库筛选纵向排列；详情页单栏；表格横向滚动 |
| `< 700px` | 内容 14px 留白；Hero 标题 23px；统计卡单列；热力图内部横向滚动；设计规范表格横向滚动 |

原则：**页面本身不出现横向滚动**；需要横向浏览的内容（热力图、宽表格）放在自己的滚动容器里。

### 6.3 页面节奏

每个页面遵循同一套呼吸：

1. 顶栏：我在哪、能做什么；
2. Hero / 页头：今天最重要的一件事；
3. 统计或筛选：给我一个判断依据；
4. 主内容：题目、面试、图表；
5. 侧栏 / 页脚：补充信息与下一步。

## 7. 组件规范

### 7.1 侧栏（书封）

- 深墨底 + 右侧 3px 朱砂「书脊」。
- 品牌印章 40×40，衬线「题」字，朱砂底、米色字、3px 硬阴影。
- 导航项高 40px，活动项左侧 2px 朱砂内阴影，背景为 9% 米色。
- 底部：连续回想（虚线框）+ 主题切换 + 设计规范入口 + 本地存储说明。
- 折叠时隐藏所有文字与徽章，图标居中；主题切换只剩图标。

### 7.2 顶栏

- 左侧 32px 图标按钮折叠侧栏。
- 中间：当前页标题（衬线 16px）+ 英文副标题（等宽 9px）。
- 右侧：全局搜索（`Ctrl K`）、日期、主按钮「快速记题」。
- 搜索框为纸色内凹，聚焦时朱砂 1px 边框 + 3px 柔光。

### 7.3 Hero（今日页）

- 墨色封面，右上有巨大的「面」字水印（230px，衬线，4% 透明度），底部裁切。
- 左侧：等宽小标签「TODAY'S REVIEW」、衬线问候语、今日待回想数与连续天数。
- 右侧：三行「今日进度」+ 三个操作：开始记忆训练（米色主按钮）、记录一道题、记一场面试（幽灵按钮）。
- 暗色下封面更深，朱砂光晕更弱；水印不变。

### 7.4 统计卡

- 4 列，纸片底、1px 边框、3px 硬阴影。
- 左上：等宽 9px 标签；中间：衬线 34px 数字；右下：小图标（朱砂 / 苔绿 / 赭石 / 石青）。
- 悬停上移 2px，硬阴影增至 5px；数字不做滚动动画。

### 7.5 题目卡

- 纸片底，左侧 3px 分类色；右上角折角（`::after` 三角），像一张索引卡。
- 第一行：分类 pill + 收藏星；标题 15px / 600；摘要 12.5px / 2 行截断。
- 标签行：`#标签` 等宽 10px，底色 6% 墨；页脚：回想次数、公司。
- 悬停：上移 2px、硬阴影 5px、折角略深；活动态回到原位。
- 列表视图与卡片视图共用同一套颜色和间距，只用布局切换。

### 7.6 筛选区

- 外层是纸片，内部控件不使用独立卡片。
- 输入框 / 下拉框高 36px，纸色底，1px 边框；聚焦朱砂。
- 主要筛选一行，更多筛选可折叠；移动端纵向排列，按钮全宽。
- 「重置」是文字按钮，不与主按钮抢视觉。

### 7.7 按钮

| 类型 | 外观 | 用途 |
| --- | --- | --- |
| Primary | 朱砂底、米色字、1px 深朱砂边、3px 硬阴影 | 保存、开始记忆训练、主操作 |
| Default | 纸色底、1px 边框、墨色字 | 次要操作 |
| Ghost | 透明底、1px 米色边（Hero 内） | 封面上的次级动作 |
| Text | 无底无边、朱砂字 | 重置、查看全部、取消 |

- 高度 36px；小按钮 28px；图标按钮 32×32。
- 悬停：Primary 变深、上移 1px；Default 边框变深、底色 `--surface-2`。
- 按下：阴影归零、下移 1px。
- 焦点：2px 朱砂外环，偏移 2px；不要移除 outline。

### 7.8 标签与徽章

- 分类 pill：分类色 12% 底 + 分类色与墨混合后的文字；圆角 3px；前置 5px 圆点。
- 难度 / 记忆状态 pill：等宽 9px，对应语义色；不要用纯红绿。
- 标签 chip：`#` 前缀，6% 墨底，10px 等宽。
- 徽章：朱砂底、米色字、3px 圆角；数字用等宽。

### 7.9 表单

- Label 12px / 600，和控件间距 6px；必填用朱砂星号。
- 输入框：纸色底、1px 边框、6px 圆角、36px 高；placeholder 用 `--text-3`。
- Textarea 最小 96px；Markdown 编辑器分「写作 / 预览」两个页签，工具栏在顶部。
- 校验错误：1px 朱砂边框 + 12px 朱砂说明；不要只靠颜色。
- 保存栏在长表单底部粘性显示，主按钮在右。

### 7.10 表格

- 容器纸片，表头 `--surface-2`，10px 等宽大写。
- 行高 52px；分隔线 `--border`；悬停行底色 `--surface-2`。
- 数字列右对齐、等宽；操作列靠右，文字按钮。
- 移动端外层横向滚动，不压缩列宽到不可读。

### 7.11 弹窗

- 600px 宽（移动端 `calc(100vw - 28px)`），纸色底，10px 圆角，1px 边框。
- 标题衬线 20px；关闭按钮 32×32；遮罩为墨色 45%（暗色 72%）。
- 底部按钮右对齐，主按钮在右；危险操作使用朱砂文字按钮 + 二次确认。

### 7.12 Markdown 阅读区

- 正文 14px / 1.8，最大宽度 72ch。
- 行内代码：`--surface-2` 底、1px 边框、等宽 12px。
- 代码块：暖色底（不使用冷灰黑），顶部有语言标签；行内高亮使用赭石 / 苔绿 / 石青，不用霓虹色。
- 引用：2px 朱砂左边线 + 淡墨字；表格与列表使用细线。
- 所有 HTML 经 DOMPurify 清洗；代码高亮只影响颜色，不改变结构。

### 7.13 热力图

- 17 周 × 7 天，单元格 13px、间距 3px、圆角 3.5px。
- 颜色只用朱砂浓度（`--hm-0..4`），图例从「少」到「多」。
- 月份标签与星期标签用 9–10px 等宽、淡墨。
- 移动端容器内部横向滚动，不压缩单元格到 5px 以下。

### 7.14 回想卡

- 单题居中，最大宽度 860px；题目衬线 28px。
- 答案折叠时显示「先自己想，再翻答案」；展开后 180ms 淡入。
- 四个评价按钮等宽：忘记（朱砂）/ 有点难（赭石）/ 记得（苔绿）/ 很简单（石青）。
- 键盘：`Space` / `Enter` 翻答案，`1–4` 评价；按钮上显示快捷键角标。
- 进度条 5px，朱砂实色，不使用渐变。

### 7.15 空状态

- 居中等宽小标签「NOTHING HERE YET」+ 衬线标题 + 一句解释 + 主按钮。
- 图标用 1px 虚线圆角框，不使用大面积插画。
- 空状态也要给出下一步，而不只是「暂无数据」。

## 8. 动效

### 8.1 Token

```css
--dur-fast: 120ms;   /* 悬停、按下、颜色 */
--dur: 180ms;        /* 卡片抬起、展开 */
--dur-slow: 260ms;   /* 页面入场、较大的位移 */
--ease-out: cubic-bezier(.16, 1, .3, 1);
--ease-in: cubic-bezier(.7, 0, .84, 0);
```

### 8.2 编排

- 页面入场：直接子元素 `opacity 0 → 1`、`translateY(8px) → 0`，每个延迟 35ms，总时长不超过 260ms。
- 卡片悬停：`translateY(-2px)`，阴影 3px → 5px，180ms ease-out。
- 按钮按下：`translateY(1px)`，阴影归零，120ms。
- 弹窗：遮罩淡入 180ms，面板 `scale(.98) → 1` + 淡入 180ms。
- 翻答案：内容 `opacity 0 → 1`，120ms；不做 3D 翻转。
- 数字与图表：不做逐位滚动；图表路径可以 600ms 绘制，但必须可中断。

### 8.3 禁止

- 不要用 `transition: all`。
- 不要给大面积背景做持续动画。
- 不要用弹跳（bounce）缓动；纸的惯性是「停得快」，不是「弹回来」。
- 不要用超过 300ms 的悬停反馈。

### 8.4 降级

```css
@media (prefers-reduced-motion: reduce) {
  *, *::before, *::after {
    animation-duration: .01ms !important;
    transition-duration: .01ms !important;
  }
}
```

页面入场与示范动画在 reduced-motion 下完全关闭。

## 9. 可访问性

- **对比度**：正文 / 背景 ≥ 7:1；次级文字 ≥ 4.5:1；`--text-3` 已从 `#8A7F6C` 调深到 `#756A58`，暗色为 `#9A8C76`。
- **焦点可见**：所有可交互元素保留 `:focus-visible` 2px 朱砂外环；不要用 `outline: none` 清掉。
- **键盘**：`Ctrl/⌘ K` 搜索、`Ctrl/⌘ N` 快速记题、`Ctrl/⌘ S` 保存、记忆训练页 `Space/Enter` 翻面、`1–4` 评价。
- **语义**：图标按钮有 `aria-label`；装饰性水印 `aria-hidden`；状态不只靠颜色，始终有文字。
- **触控目标**：按钮至少 32×32，移动端主按钮 44px 高。
- **动效**：尊重 `prefers-reduced-motion`；不自动播放循环动画。
- **字体缩放**：正文使用相对单位；200% 缩放时页面不横向溢出（已在 390px 宽度验证）。

## 10. 主题实现

### 10.1 文件职责

| 文件 | 职责 |
| --- | --- |
| `tokens.css` | 唯一变量源：颜色、字体、间距、圆角、阴影、动效、Element Plus 变量 |
| `main.css` | 结构、布局、组件骨架；保留历史类名 |
| `theme.css` | 视觉层：纸张纹理、墨色侧栏、卡片、Hero、表单、Markdown、EP 覆盖、响应式 |

加载顺序（`web/src/main.js`）：

```js
import './styles/tokens.css'
import './styles/main.css'
import './styles/theme.css'
```

`theme.css` 必须最后加载，才能覆盖 `main.css` 里的旧渐变与旧色值。

### 10.2 切换主题

- 主题状态存在 `localStorage` 的 `ib-theme`（`light` / `dark`）。
- 根节点 `<html class="dark">` 时命中 `tokens.css` 的 `html.dark`。
- 首屏在 `index.html` 的内联脚本里读取并加类，避免闪烁。
- 所有组件颜色走 CSS 变量；不要在新的组件里写死十六进制色值。

### 10.3 Element Plus 映射

Element Plus 的 `--el-*` 变量在 `tokens.css` 中映射到本项目 token：

```css
--el-color-primary: var(--primary);
--el-bg-color: var(--surface);
--el-text-color-primary: var(--text);
--el-border-color: var(--border);
--el-border-radius-base: 6px;
--el-font-family: var(--font-body);
```

组件级覆盖集中在 `theme.css` 的「Element Plus」段：按钮、输入、下拉、表格、弹窗、消息、分页、标签、开关、日期选择器。

### 10.4 分类色

分类颜色由后端 `Category.color` 存储，前端展示时统一混合：

```js
color: color-mix(in srgb, ${color} 72%, var(--text));
background: color-mix(in srgb, ${color} 12%, transparent);
```

这样同一个分类色在亮色纸面和暗色布面上都能保持可读，不需要维护两套分类色。

### 10.5 新增页面检查清单

- [ ] 使用 `tokens.css` 的变量，不新增硬编码颜色
- [ ] 标题用 `--font-display`，正文用 `--font-body`，元信息用 `--font-mono`
- [ ] 卡片：`--surface` + 1px `--border` + `--shadow-hard`
- [ ] 主操作只有一个，且用 Primary
- [ ] 空状态有下一步
- [ ] 1440 / 1024 / 390 三个宽度无页面横向滚动
- [ ] 亮色 / 暗色都检查一遍
- [ ] 键盘可完成主流程，焦点可见
- [ ] `prefers-reduced-motion` 下不晕

## 12. 方法说明

这套视觉不是套用某个现成后台模板，而是按以下方法重新制定的：
