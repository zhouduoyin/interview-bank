# 面试记忆助手 · 产品定义

> 一句话：把每一次面试里被问到、事后却想不起来的问题，变成下一次可以调用的长期记忆。

## 1. 为什么需要它

面试准备最常见的失败不是“没看过”，而是：

- 面试现场被问住，回家路上还记得，第二天就只剩一个模糊印象；
- 收藏了很多题，答案也看过，但真正被问时说不完整；
- 面试一场接一场，复盘写在备忘录里，和题目、答案、公司完全脱节；
- 回想靠“今天想刷题”的意志力，没有明确的下一步。

面试记忆助手不是又一个题库，而是一套**个人记忆系统**：记录 → 主动回想 → 诚实评分 → 自动安排 → 面试复盘 → 反向补充题库。

## 2. 目标用户

- 正在密集面试的 1–5 年经验开发者；
- 前端 / 后端 / 全栈都可以用，题库结构不绑定语言；
- 希望把面试准备做成一个长期、可复盘、数据在自己手里的系统；
- 更看重“下次能不能讲出来”，而不是“收藏了多少题”。

## 3. 核心闭环

```text
        ┌───────────────┐
        │   ① 捕获       │  面试后 10 分钟内记题
        └───────┬───────┘
                ↓
        ┌───────────────┐
        │   ② 回想       │  先合上答案，主动提取
        └───────┬───────┘
                ↓
        ┌───────────────┐
        │   ③ 评分       │  忘记 / 有点难 / 记得 / 很简单
        └───────┬───────┘
                ↓
        ┌───────────────┐
        │   ④ 安排       │  间隔回想，自动排下一次
        └───────┬───────┘
                ↓
        ┌───────────────┐
        │   ⑤ 复盘       │  面试档案串联现场与题目
        └───────────────┘
```

产品只围绕这条闭环做功能；任何不能帮助“记住 / 复盘”的功能，都默认不做。

## 4. 信息架构

| 一级入口 | 回答的问题 | 主要动作 |
| --- | --- | --- |
| **今日** | 今天最该做什么？ | 看今日待回想、连续回想、薄弱分类，进入训练 |
| **记忆训练** | 这些题我现在能讲出来吗？ | 主动回想、核对答案、四档评分 |
| **题库** | 我被问过什么？答案是什么？ | 搜索、筛选、记录、编辑、关联面试 |
| **面试档案** | 这场面试发生了什么？ | 记录公司 / 轮次 / 自评 / 复盘，关联题目 |
| **成长洞察** | 我的记忆结构哪里薄？ | 看趋势、分类稳固率、难度和标签分布 |
| **记忆方法** | 这个系统为什么这样安排？ | 理解闭环、评分和间隔规则 |
| **设置与数据** | 数据怎么备份、迁移、清理？ | 导入导出、分类标签、危险操作 |

设计原则：**今日是入口，训练是动作，题库和面试是资产，洞察是反馈，方法是解释。**

## 5. 功能地图

### 5.1 记忆闭环

- 快速记题：全局 `Ctrl + N`，先记问题，答案后补；
- 今日任务：按 `nextReviewAt` 取出到期题目；
- 主动回想：默认隐藏答案，支持空格 / 回车核对；
- 四档评分：忘记、有点难、记得、很简单，对应 SM-2 简化版间隔；
- 训练收尾：显示本轮评分分布，支持再来一轮；
- 记忆状态：待开始 / 加固中 / 长期记忆，可手动调整；
- 薄弱分类：按分类稳固率自动挑出“优先加固”的方向。

### 5.2 知识资产

- 题目：Markdown 题目描述、参考答案、个人备注；
- 分类 / 标签 / 难度 / 来源公司 / 来源岗位 / 收藏；
- 卡片与表格双视图、批量操作、分页；
- 题目详情：答案折叠、回想历史时间线、关联面试；
- 内置 75 道前端题库，可一键导入且按标题去重。

### 5.3 面试档案

- 公司、岗位、轮次、日期、渠道、薪资、结果、自评；
- 面试复盘 Markdown；
- 关联题目 + 面试官追问 + 自己的回答；
- 从面试详情反查“这道题出现在哪些面试里”。

### 5.4 反馈与数据

- 17 周回想热力图、30 天趋势、分类记忆结构；
- 连续回想天数、稳固率、累计回想次数；
- JSON 全量备份 / 恢复，Markdown 导出；
- 分类与标签管理、示例数据清理、全量清空；
- 亮 / 暗主题、侧栏折叠、全局搜索、响应式布局。

## 6. 明确不做

- 不做公开题库社区、排行榜、社交关注；
- 不做 AI 自动生成答案冒充“标准答案”；
- 不做多用户权限、团队空间（当前是单用户本地优先）；
- 不把“收藏数 / 刷题数”当成核心指标；
- 不为了功能数量牺牲记录速度和回想节奏。

## 7. 成功指标

| 指标 | 定义 | 期望方向 |
| --- | --- | --- |
| 回想完成率 | 当日到期题目中被评分的比例 | 上升 |
| 长期记忆率 | 长期记忆题 / 总题数 | 上升 |
| 连续回想天数 | 有回想记录的连续天数 | 上升 |
| 面试复盘率 | 有复盘内容的面试 / 总面试 | 上升 |
| 记录后 24h 补充率 | 新题在 24h 内补答案的比例 | 上升 |
| 到期积压 | 超过 7 天未处理的到期题 | 下降 |

## 8. 迭代路线

### 已完成（v2 基础）

- 品牌统一为「面试记忆助手」；
- 信息架构改为「今日 / 记忆训练 / 题库 / 面试档案 / 成长洞察 / 记忆方法 / 设置与数据」；
- 今日页增加“优先加固”分类入口；
- 新增记忆方法页，解释闭环与间隔规则；
- 内置前端题库扩充到 75 道。

### 下一步

- 每日回想目标与周报；
- 题目“记忆强度”可视化（不只是状态标签）；
- 面试复盘 → 一键生成待补题目；
- 导出 / 导入的版本号与迁移提示；
- 可选的 AI 复盘摘要（本地开关，不替代标准答案）。
