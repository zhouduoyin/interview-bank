 面试记忆助手 · 先看这里（第一次运行必读）
============================================================

【最重要的一句话】

不用分别启动前端、后端、数据库。

双击项目根目录的 start.bat，等浏览器自动打开：

    http://127.0.0.1:8090

关闭那个命令行窗口，服务就停止。
你的题目、回想记录不会丢，数据保存在：

    data\interview-bank.mv.db


------------------------------------------------------------
 一、三个部分分别在哪？
------------------------------------------------------------

web\      前端，Vue 3 + Vite
          放页面、组件、样式、前端依赖。
          代码入口：web\src\main.js

server\   后端，Spring Boot + Java
          放 API、业务逻辑、数据库访问。
          代码入口：server\src\main\java\com\interviewbank\InterviewBankApplication.java

data\     默认数据库（H2）
          不用安装 MySQL，它就是一个本地文件：
          data\interview-bank.mv.db
          这个文件是程序自动生成的，删掉就等于清空数据。

sql\      可选 MySQL 的建库脚本
          sql\init.sql 只是 SQL 脚本，不是数据库程序本身。
          只有你明确要用 MySQL 时才需要它。

最终可运行程序：

    server\target\interview-bank.jar

这个 jar 里已经打包了前端页面，所以“最简单模式”只运行它一个，
不需要再启动 web\ 里的前端。

------------------------------------------------------------

------------------------------------------------------------
 三、启动方式 A：最简单（推荐，日常使用）
------------------------------------------------------------

适合：只想打开页面记题、回想，不改代码。

1. 双击根目录的 start.bat。
2. 第一次启动约 20 秒，浏览器会自动打开：
   http://127.0.0.1:8090
3. 停止：关闭命令行窗口，或运行：
   .\stop.ps1

这个模式不需要安装 Node.js，也不需要 MySQL。
只需要电脑上有 Java 17 或更高版本。

如果双击后提示找不到 jar，说明构建产物被删了：
先运行 .\build.ps1，或者按 README 的“从 GitHub 克隆”重新构建。


------------------------------------------------------------
 四、启动方式 B：开发前端（改 Vue 页面时用）
------------------------------------------------------------

适合：你要修改 web\ 里的页面、样式、交互。

需要两个终端。

终端 1：启动后端 API（在项目根目录执行）

    java -jar server\target\interview-bank.jar

如果你刚改过后端 Java 代码，先重新构建，再启动：

    .\build.ps1
    java -jar server\target\interview-bank.jar

不要把工作目录切到 server 里再启动，否则 H2 会在
server\data 下新建另一个数据库，看不到现在的题目。
从项目根目录执行 java -jar，读的才是 data\interview-bank.mv.db。

终端 2：启动前端开发服务器

    cd web
    npm ci
    npm run dev

然后打开：

    http://127.0.0.1:5173

Vite 会把 /api 请求代理到后端 http://127.0.0.1:8090。
所以后端必须先启动，否则页面没有数据。

注意：这个模式不要再用 start.bat 启动第二个后端，
否则 8090 端口会冲突。


------------------------------------------------------------
 五、启动方式 C：MySQL 模式（正式使用 / 想看三端分离）
------------------------------------------------------------

适合：你想把数据库换成真正的 MySQL，或者部署到服务器。

结构是：

    Vue 前端  --/api-->  Spring Boot 后端  --JDBC-->  MySQL

步骤：

1. 先安装并启动 MySQL。
2. 初始化数据库（在项目根目录执行，输入 MySQL root 密码）：

    mysql -u root -p -e "source sql/init.sql"

3. 启动后端（默认连 127.0.0.1:3306，用户 interview）：

    .\start-mysql.bat

4. 另开终端启动前端：

    cd web
    npm ci
    npm run dev

5. 打开 http://127.0.0.1:5173

如果 MySQL 的地址、账号、密码不是默认值，先设置环境变量再启动：

    $env:DB_URL = "jdbc:mysql://127.0.0.1:3306/interview_bank?useUnicode=true&characterEncoding=utf8&useSSL=false&allowPublicKeyRetrieval=true&serverTimezone=UTC"
    $env:DB_USERNAME = "interview"
    $env:DB_PASSWORD = "你的密码"
    .\start-mysql.bat

完整说明见 docs\mysql.md。


------------------------------------------------------------
 六、启动方式 D：Docker 三端一起启动（可选）
------------------------------------------------------------

适合：电脑装了 Docker Desktop，想一条命令把 MySQL、后端、前端都跑起来。

    docker compose up -d --build

启动后：

    前端页面   http://127.0.0.1:18090
    后端 API   http://127.0.0.1:18089/api/stats/dashboard
    MySQL      127.0.0.1:13307

停止：

    docker compose down

不想用 Docker 时，完全不用管这个文件。

------------------------------------------------------------
 八、哪些是源码，哪些是自动生成的？
------------------------------------------------------------

可以改：
    web\src\                前端页面和组件
    server\src\             后端 Java 代码和配置
    sql\init.sql            MySQL 建库脚本

不要手改（会自动生成/覆盖）：
    web\node_modules\       前端依赖
    web\dist\               前端构建产物
    server\target\          Maven 构建产物

不要随便删：
    data\                   你的 H2 数据库，删了就清空题目和记录


------------------------------------------------------------
 九、常见问题
------------------------------------------------------------

1）双击 start.bat 没反应 / 一闪而过
   - 可能没装 Java。命令行执行 java -version 检查，需要 17+。
   - 可能缺少 server\target\interview-bank.jar，运行 .\build.ps1 重新构建。

2）打开 8090 报“端口被占用”
   - 可能已经启动过一个实例，先运行 .\stop.ps1，再重新启动。
   - 或换端口：$env:SERVER_PORT = "8091"; .\start.ps1

3）前端 npm run dev 启动失败
   - 先确认装了 Node.js 22.13 或更高版本。
   - 在 web\ 目录执行 npm ci，不要漏掉这一步。

4）页面能打开，但没有题目 / 接口报错
   - 开发模式下确认后端 8090 已经启动。
   - 最简模式下确认 start.bat 的窗口没有关掉。

5）我想找回原来的数据
   - 默认数据在 data\interview-bank.mv.db，不要删。
   - 换 MySQL 后不会自动迁移旧 H2 数据，迁移方法见 docs\mysql.md。

6）我还是不知道选哪种
   - 日常记题：方式 A，双击 start.bat。
   - 改前端页面：方式 B。
   - 正式部署/三端分离：方式 C 或 D。
